# 여행 영상 대시보드

여행 영상을 올려 두고, 아이디·비밀번호를 아는 사람이면 누구나 볼 수 있는 대시보드입니다.
외부 패키지 없이 Node.js(18 이상)만 있으면 실행됩니다.

## 계정은 두 개
| 계정 | 할 수 있는 일 |
| --- | --- |
| **시청용** (다른 사람에게 공유) | 영상 보기, 검색·필터 |
| **관리자** (나만 사용) | 위 기능 + 업로드, 정보 수정, 썸네일 변경, 삭제, 계정 변경 |

권한은 서버에서 검사합니다. 시청용 계정으로는 업로드·수정 요청을 보내도 거부되고, 로그인하지 않으면 영상 파일 주소를 알아도 볼 수 없습니다.

## 실행
```bash
cd video-dashboard
ADMIN_PASSWORD='내관리자비밀번호' VIEWER_PASSWORD='공유할비밀번호' node server.js
# → http://localhost:3000
```
- 처음 실행할 때 계정이 만들어집니다. 비밀번호를 지정하지 않으면 임의로 만들어 터미널에 한 번 보여줍니다.
- 기본 아이디는 `admin` / `guest` 이며 `ADMIN_ID`, `VIEWER_ID`로 바꿀 수 있습니다.
- 이후에는 로그인 → **설정**에서 아이디·비밀번호를 바꿉니다. 비밀번호를 바꾸면 그 계정의 기존 로그인은 모두 풀립니다.
- 관리자 비밀번호를 잊었다면 `node server.js reset` 으로 두 계정을 다시 만듭니다(영상은 그대로).

| 환경변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `3000` | 포트 |
| `DATA_DIR` | `./data` | 영상·썸네일·설정 저장 위치 (**백업 대상**) |
| `SITE_TITLE` | `여행 필름` | 화면에 표시되는 이름 |
| `MAX_UPLOAD_MB` | `2048` | 영상 한 개 최대 크기 |
| `TRUST_PROXY` | 꺼짐 | 리버스 프록시(HTTPS) 뒤에서 실행하면 `1` |

## 화면
- **대표 영상**: 고정한 영상(없으면 가장 최근 여행)이 첫 화면에 크게 표시
- **요약**: 영상 수, 총 재생시간, 여행지 수, 총 조회수
- **찾기**: 검색(제목·여행지·태그), 여행지 칩, 연도, 정렬
- **카드**: 마우스를 올리면 소리 없이 미리보기, 누르면 재생
- **재생**: 이전/다음, 끝나면 다음 영상 이어보기
- **업로드(관리자)**: 여러 개를 끌어다 놓기, 진행률 표시, 길이와 썸네일 자동 추출
- **수정(관리자)**: 제목·설명·여행지·날짜·태그, 대표 고정, 썸네일 교체(이미지 파일 또는 재생 중 "지금 장면을 썸네일로"), 삭제

## 영상 형식
MP4, MOV, WebM을 올릴 수 있습니다. 모든 브라우저에서 재생되게 하려면 **H.264 + AAC MP4**로 내보내는 것을 권합니다.
아이폰 기본 설정(HEVC)으로 찍은 MOV는 크롬·안드로이드 일부에서 재생되지 않을 수 있습니다.

## 다른 사람이 접속하게 하려면
이 서버가 인터넷에서 접근 가능한 곳에서 계속 켜져 있어야 합니다.
- **집 PC·NAS**: 실행해 두고 Cloudflare Tunnel, Tailscale Funnel 등으로 주소를 공개
- **클라우드 서버(VPS)**: Docker로 실행하고 Caddy 같은 리버스 프록시로 HTTPS 연결

```bash
docker build -t travel-videos .
docker run -d --name travel-videos -p 3000:3000 -v travel-videos-data:/data \
  -e ADMIN_PASSWORD='...' -e VIEWER_PASSWORD='...' -e TRUST_PROXY=1 travel-videos
```

비밀번호가 그대로 오가지 않도록 **반드시 HTTPS로 공개**하세요. GitHub Pages 같은 정적 호스팅에서는 동작하지 않습니다(로그인 확인과 영상 저장에 서버가 필요).

## 보안 메모
- 비밀번호는 scrypt 해시로만 저장, 로그인 실패 10회 시 15분간 차단
- 세션은 서명된 HttpOnly 쿠키(시청용 30일, 관리자 7일)
- 업로드 파일은 실제 내용으로 형식을 확인하고, 파일 이름은 서버가 새로 만듭니다
