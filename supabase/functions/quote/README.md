# 시세 조회 함수 (quote)

자산관리 대시보드가 주식·비트코인 현재가를 가져올 때 쓰는 작은 서버 함수예요. 브라우저가 시세 사이트에 직접 접속하지 못하는 문제를 피하려고 Supabase 서버에서 대신 조회합니다.

- 주소: `https://<프로젝트>.supabase.co/functions/v1/quote?kind=crypto|kr|us&sym=<심볼>`
- 개인 정보는 다루지 않고, 공개 시세 심볼만 전달받아요.
- 세 곳(업비트, 네이버 금융, 스투큐)만 조회하며 그 밖의 주소로는 요청하지 않아요.

## 배포 방법 (한 번만, 약 3분)
1. Supabase 대시보드 → 왼쪽 메뉴 **Edge Functions** → **Deploy a new function** → **Via Editor**
2. 함수 이름을 **`quote`** 로 입력합니다.
3. 편집기의 기본 코드를 지우고 [`index.ts`](index.ts) 내용 전체를 붙여넣습니다.
4. **Deploy function** 을 누릅니다. **Verify JWT** 옵션은 켠 채로 두세요(앱이 공개 키로 호출해요).

배포 후 앱을 새로고침하면, 자산 탭 상단의 "시세 N개 자동 갱신" 문구로 성공 여부를 볼 수 있어요.

## 주의
- 조회 대상 사이트의 응답 형식이 바뀌면 `index.ts` 의 해당 부분만 고치면 됩니다.
- 함수가 없거나 조회에 실패하면 앱은 직접 입력한 현재가를 사용해요.
